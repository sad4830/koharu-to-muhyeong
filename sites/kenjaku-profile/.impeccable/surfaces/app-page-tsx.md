# 켄자쿠 인물 기록

- 범위: `app/page.tsx` 단일 페이지
- 방문자 모드: Read
- 독자: 켄자쿠의 정체와 능력을 정확히 알고 싶은 한국어 주술회전 팬
- 독자 행동: 애니 공개 범위로 읽기 시작하고, 원할 때 원작 완결 스포일러를 직접 해제한다
- 근거: 애니 공식 캐릭터·사멸회유 페이지, 원작 만화 회차, 공식 캐릭터 이미지
- 제약: 미확인 신체 수치·등급을 만들지 않으며 원작 스포일러를 기본 노출하지 않는다
- 방향: 해부 병리도감과 육체 교체 장부를 결합한 비대칭 기록물
- 기억 장면: 첫 화면을 관통한 붉은 봉합선이 켄자쿠의 공식 전신 이미지와 역대 육체명을 한 장의 증거물로 묶는다
- 대표 상호작용: 애니 기준/원작 완결 전환 시 봉인된 문단과 최종 상태가 같은 자리에서 해제된다
- 미해결: 없음. 공개 배포 후에도 애니 기준이 기본이며 원작 완결 범위는 독자가 직접 해제한다
