# Surface Brief: Sealed profile

- Mode: Read
- Audience: 별도로 전달받은 주소로 비공개 제출을 검토하는 힐그램 운영진
- Job: 진짜 신상, 왜곡된 성격, 살인 과거사, 심문 사상, 열린 선관을 양식 순서대로 확인한다.
- Structure: 어두워진 초상과 진술 → 비공개 기본 정보 → 외관 → 성격 → L/H/S → 특징 → 요약 → 전체 과거사 → 인과 연표 → 사상 → 선관.
- Memorable moment: 밝은 사이트와 동일한 사진 복원 문법이 먹회색 보관실로 반전된다.
- Constraint: 공개 제출 사이트로 이동하는 링크나 주소를 제공하지 않고, 검색 로봇의 색인을 차단한다.
