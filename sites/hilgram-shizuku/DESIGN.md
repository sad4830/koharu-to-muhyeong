# Design System: Mikage Shizuku Public Record

## Creative North Star

공개 프로필은 흐린 복원지 위에 정리된 현대적인 사진 복원 기록처럼 보인다. 초상과 이름이 첫 화면을 나누고, 양식 항목은 얇은 선과 넉넉한 여백으로 이어진다. 장식은 라일락 한 색, 크롭 마크, 평행선, 음성 기록선으로 제한한다.

## Color

- 배경 `#f5f3f7`
- 표면 `#fcfbfd`
- 본문 `#24212b`
- 보조문 `#625d6c`
- 선 `#d8d1df`
- 강조 `#694b7d`
- 옅은 강조면 `#e9ddf1`

## Typography

- 인물명: 자체 호스팅한 `Shizuku Serif`, 굵기 700, 최대 6rem
- 본문과 UI: 한국어 시스템 산세리프 스택
- 본문 행간 1.9, 읽기 폭 최대 72ch

## Composition

- 데스크톱은 왼쪽 고정 초상, 오른쪽 기록문으로 나눈다.
- 모바일은 작은 초상을 먼저 보여 준 뒤 이름과 본문을 세로로 잇는다.
- 상단에는 단일 공개 프로필 상태만 조용히 표시한다.
- 각 섹션은 독립 카드 대신 하나의 연속 기록지 안에서 1px 선으로 구분한다.

## Motion and Accessibility

- 최초 초상은 아래에서 복원되는 클립 전환, 본문 상태는 짧은 블러 해제 전환을 사용한다.
- 콘텐츠는 애니메이션 전에도 보이는 상태를 기본으로 한다.
- `prefers-reduced-motion`에서는 모든 전환을 제거한다.
- 초점 표시, 텍스트 선택, 스크롤바까지 라일락 계열로 맞춘다.

## Privacy Boundary

- 이 표면에는 공개 제출 정보만 존재한다.
- 다른 자료로 이동하는 링크, 경로, 상태, 메타 설명을 포함하지 않는다.
